# RPS Battlegrounds

一个带商店、道具、天赋和多人对战流程的石头剪刀布游戏。现在推荐使用 Web 界面游玩。

## 启动 Web 界面

在项目根目录运行：

```bash
python web/app.py
```

然后打开浏览器访问：

```text
http://127.0.0.1:8001/
```

## 创建游戏

1. 第一个进入的玩家勾选“创建本机服务器”。
2. 填写玩家名。
3. 设置玩家数，范围是 2 到 8。
4. 点击“进入游戏”。

当所有玩家加入后，对局会自动开始。

## 加入游戏

本机测试时：

1. 再打开一个浏览器窗口或标签页。
2. 取消勾选“创建本机服务器”。
3. 服务器 IP 填 `127.0.0.1`。
4. 输入玩家名并进入游戏。

局域网联机时，其他玩家把服务器 IP 填为房主电脑的局域网 IP。游戏 TCP 服务器使用端口 `5555`，Web 界面默认使用端口 `8001`。

## 游戏流程

每轮主要分为两个阶段：

- 对战阶段：选择石头、剪刀或布。每种出拳有数量限制，用完后不能再选。
- 商店阶段：购买道具或天赋，也可以刷新商店或退出商店等待下一轮。

Web 界面左侧会显示：

- 自己的血量、金币、攻击、利息、连胜/连败
- 当前出拳包
- 自己拥有的道具和天赋
- 对手天赋
- 全局血量

战况日志会显示每小局的出拳、比分、双方使用的道具，以及触发过的天赋事件。

## 命令行版本

也可以运行原来的命令行入口：

```bash
python main.py
```

按提示选择创建服务器或加入游戏。

## 备注

- Python 标准库即可运行 Web 界面，不需要额外安装 Web 框架。
- 如果修改了代码，刷新浏览器即可更新前端资源；如果改了后端逻辑，需要重启 `python web/app.py`。
